# 林凡斐 · 个人作品集

一个展示个人项目作品的静态作品集网页,采用原生 HTML / CSS / JavaScript 构建,不依赖任何前端框架和第三方 UI 组件库,兼容桌面端与移动端。

## 主要功能

- **个人简介侧边栏**:头像、简介、技能标签与锚点导航,桌面端左侧固定、移动端折叠为汉堡菜单
- **项目作品展示**:项目数据与页面渲染分离,按完成时间倒序自动排列,图文左右穿插布局;配图加载失败时自动显示占位块
- **明暗主题切换**:右上角悬浮按钮一键切换浅色 / 深色模式,全站配色同步适配;主题选择通过 localStorage 持久化,刷新后保持,无闪烁
- **导航滚动高亮**:滚动页面时自动高亮当前板块对应的导航项
- **响应式布局**:≥1024px 为左右分栏,更窄屏幕自动切换为上下堆叠的移动端布局

## 技术栈

| 类别 | 说明 |
|---|---|
| HTML | 语义化页面结构(原生,无框架) |
| CSS | CSS 变量驱动配色(明暗主题)、Flexbox / Grid 响应式布局 |
| JavaScript | 原生 ES5+ 语法,数据渲染、主题切换、滚动监听(IntersectionObserver) |

## 运行方式

纯静态站点,无需构建:

1. 用浏览器直接打开 `index.html` 即可;
2. 或使用 VS Code Live Server / 任意静态服务器(如 `python -m http.server`)预览。

## 目录结构

```
lab04/
├── index.html          # 页面入口
├── css/
│   ├── base.css        # 重置、配色变量(含深色主题)、基础排版
│   ├── layout.css      # 桌面 / 移动端布局
│   └── components.css  # 组件样式(导航、项目卡片、主题按钮等)
├── js/
│   ├── data-loader.js  # 读取项目数据并渲染作品列表
│   ├── theme.js        # 明暗主题切换与 localStorage 持久化
│   └── main.js         # 移动端菜单、导航滚动高亮
├── data/
│   └── projects.js     # 项目数据(新增项目只需在此追加记录)
└── images/projects/    # 项目配图
```

## 如何新增项目

在 `data/projects.js` 的 `window.PROJECTS` 数组末尾追加一条记录(字段说明见文件注释),并将配图放入 `images/projects/` 即可,无需改动其他代码。
